# Template Setting

> Introduction

![Template Menu](_images/template/template_1.png ':size=80%')

<!-- 📷 截图待补充：Template 菜单/模板列表页 -->

In `Template`, administrators can create and manage TV interface templates. Templates define the layout and style of the terminal home page and menus, allowing the hotel to customize the TV interface without modifying the APK. A template is edited with a visual editor, and the edited content is delivered to the terminal devices.

## Template List

> Introduction

![Template List](_images/template/template_2.png ':size=80%')

<!-- 📷 截图待补充：Template List 页面 -->

In `Template List`, administrators can view, create, edit, and delete templates.

Press `Add` button to create a new template.

![Template - Add](_images/template/template_3.png ':size=80%')

<!-- 📷 截图待补充：模板新增/编辑 -->

1. <font color="red">**ID**</font>: The `ID` is automatically generated by the system. It does not need to be filled in.

2. <font color="red">**Name**</font>: In `Name`, enter the name used to identify this template.

3. <font color="red">**Type**</font>: In `Type`, select the type of the template.

4. <font color="red">**Version**</font>: In `Version`, the version number of the template. It is automatically managed by the system when the template is updated.

### Template Editor

![Template Editor](_images/template/template_4.png ':size=80%')

<!-- 📷 截图待补充：模板编辑器界面 -->

Click the `Edit` button on a template to open the visual template editor, where administrators can:

- Arrange components (e.g. menu entries, images, text) on the interface with drag & drop.
- Configure the properties of each component (position, size, color, content).
- Copy components to reuse them.
- Undo/redo editing operations.
- Save the template and publish it to the terminal devices.

## Template Resource

> Introduction

![Template Resource](_images/template/template_5.png ':size=80%')

<!-- 📷 截图待补充：Template Resource 列表页 -->

In `Template Resource`, administrators manage the resources (images, etc.) used by the templates. Resources are uploaded once and can be referenced by multiple templates.

Press `Add` button to upload a new template resource.

![Template Resource - Add](_images/template/template_6.png ':size=80%')

<!-- 📷 截图待补充：模板资源上传/编辑 -->

<font color="red">**Name**</font>: In `Name`, enter the name used to identify this resource.

<font color="red">**Type**</font>: In `Type`, select the type of the resource.

<font color="red">**Image**</font>: In `Image`, upload the resource file. The uploaded file will be stored on the server and referenced by templates through its path.
