# Paramètres des modèles

> Introduction

![Menu Modèles](_images/template/template_1.png ':size=80%')

<!-- 📷 Capture à compléter : menu/liste des modèles -->

Dans `Modèles`, les administrateurs peuvent créer et gérer des modèles d'interface TV. Les modèles définissent la disposition et le style de la page d'accueil et des menus du terminal, ce qui permet à l'hôtel de personnaliser l'interface TV sans modifier l'APK. Un modèle est édité avec un éditeur visuel et le contenu édité est livré aux terminaux.

## Liste des modèles

> Introduction

![Liste des modèles](_images/template/template_2.png ':size=80%')

<!-- 📷 Capture à compléter : page Liste des modèles -->

Dans `Liste des modèles`, les administrateurs peuvent consulter, créer, modifier et supprimer des modèles.

Appuyez sur le bouton `Ajouter` pour créer un nouveau modèle.

![Modèle - Ajouter](_images/template/template_3.png ':size=80%')

<!-- 📷 Capture à compléter : ajout/modification d'un modèle -->

1. <font color="red">**ID**</font> : L'`ID` est généré automatiquement par le système. Il n'est pas nécessaire de le remplir.

2. <font color="red">**Nom**</font> : Dans `Nom`, saisissez le nom permettant d'identifier ce modèle.

3. <font color="red">**Type**</font> : Dans `Type`, sélectionnez le type du modèle.

4. <font color="red">**Version**</font> : Dans `Version`, le numéro de version du modèle. Il est géré automatiquement par le système lors de la mise à jour du modèle.

### Éditeur de modèles

![Éditeur de modèles](_images/template/template_4.png ':size=80%')

<!-- 📷 Capture à compléter : interface de l'éditeur de modèles -->

Cliquez sur le bouton `Modifier` d'un modèle pour ouvrir l'éditeur visuel de modèles, où les administrateurs peuvent :

- Organiser les composants (ex. entrées de menu, images, texte) sur l'interface par glisser-déposer.
- Configurer les propriétés de chaque composant (position, taille, couleur, contenu).
- Copier des composants pour les réutiliser.
- Annuler/rétablir les opérations d'édition.
- Enregistrer le modèle et le publier sur les terminaux.

## Ressource de modèle

> Introduction

![Ressource de modèle](_images/template/template_5.png ':size=80%')

<!-- 📷 Capture à compléter : page Ressource de modèle -->

Dans `Ressource de modèle`, les administrateurs gèrent les ressources (images, etc.) utilisées par les modèles. Les ressources sont téléchargées une fois et peuvent être référencées par plusieurs modèles.

Appuyez sur le bouton `Ajouter` pour télécharger une nouvelle ressource de modèle.

![Ressource de modèle - Ajouter](_images/template/template_6.png ':size=80%')

<!-- 📷 Capture à compléter : téléchargement/modification d'une ressource de modèle -->

<font color="red">**Nom**</font> : Dans `Nom`, saisissez le nom permettant d'identifier cette ressource.

<font color="red">**Type**</font> : Dans `Type`, sélectionnez le type de la ressource.

<font color="red">**Image**</font> : Dans `Image`, téléchargez le fichier de la ressource. Le fichier téléchargé sera stocké sur le serveur et référencé par les modèles via son chemin.
