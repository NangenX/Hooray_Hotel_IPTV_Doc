# Paramètres des installations

> Introduction

![Paramètres des installations](_images/facilities/facilities_1.png)

Dans `Menu Installations`, les administrateurs peuvent créer des groupes d'installations et gérer les informations des installations de l'hôtel (piscine, salle de sport, restaurant, etc.). Les informations sur les installations seront affichées sur les terminaux des chambres, ce qui permet aux clients de consulter les installations de l'hôtel et les attractions environnantes.

## Groupe d'installations

> Introduction

![Groupe d'installations](_images/facilities/facilities_group_1.png ':size=80%')

<!-- 📷 Capture à compléter : page de liste des groupes d'installations -->

Dans `Groupe d'installations`, les administrateurs créent des groupes pour catégoriser les installations. Le regroupement facilite la gestion et l'affichage conjoint des installations de la même catégorie sur le terminal.

Appuyez sur le bouton `Ajouter` pour créer un nouveau groupe d'installations.

![Groupe d'installations - Ajouter](_images/facilities/facilities_group_2.png ':size=80%')

<!-- 📷 Capture à compléter : fenêtre d'ajout/modification d'un groupe d'installations -->

<font color="red">**ID**</font> : Dans `ID`, les identifiants sont gérés et générés par le système. Il n'est pas nécessaire de les remplir.

<font color="red">**Nom**</font> : Dans `Nom`, saisissez le nom permettant d'identifier ce groupe d'installations, ex. `Installations de l'hôtel`, `Attractions environnantes`.

## Installations

> Introduction

![Installations](_images/facilities/facilities_2.png ':size=80%')

<!-- 📷 Capture à compléter : page de liste des installations -->

Dans `Installations`, les administrateurs ajoutent, modifient et suppriment les détails des installations. Chaque installation appartient à un ou plusieurs groupes d'installations et sera affichée sur le terminal pour que les clients la consultent.

Appuyez sur le bouton `Ajouter` pour créer de nouvelles informations d'installation.

![Installations - Ajouter](_images/facilities/facilities_3.png ':size=80%')

<!-- 📷 Capture à compléter : fenêtre d'ajout/modification d'une installation -->

<font color="red">**Type**</font> : Dans `Type`, saisissez le nom de l'installation, ex. `Piscine`, `Centre de remise en forme`.

<font color="red">**Contenu**</font> : Dans `Contenu`, saisissez la description détaillée de l'installation. Le contenu sera affiché sur le terminal.

<font color="red">**Groupe**</font> : Dans `Groupe`, sélectionnez le(s) groupe(s) d'installations auquel cette installation appartient. Une installation peut appartenir à plusieurs groupes.
