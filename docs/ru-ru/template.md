# Настройка шаблонов

> Введение

![Меню шаблонов](/_images/template/template_1.png ':size=80%')

<!-- 📷 Скриншот ожидается: меню/список шаблонов -->

В разделе `Шаблоны` администраторы могут создавать шаблоны интерфейса ТВ и управлять ими. Шаблоны определяют расположение и стиль главного экрана и меню терминала, что позволяет отелю настраивать интерфейс ТВ без изменения APK. Шаблон редактируется с помощью визуального редактора, а отредактированное содержимое доставляется на терминальные устройства.

## Список шаблонов

> Введение

![Список шаблонов](/_images/template/template_2.png ':size=80%')

<!-- 📷 Скриншот ожидается: страница «Список шаблонов» -->

В разделе `Список шаблонов` администраторы могут просматривать, создавать, редактировать и удалять шаблоны.

Нажмите кнопку `Добавить`, чтобы создать новый шаблон.

![Шаблон - Добавить](/_images/template/template_3.png ':size=80%')

<!-- 📷 Скриншот ожидается: добавление/редактирование шаблона -->

1. <font color="red">**ID**</font>: `ID` генерируется системой автоматически. Заполнять его не нужно.

2. <font color="red">**Название**</font>: В поле `Название` введите имя, идентифицирующее этот шаблон.

3. <font color="red">**Тип**</font>: В поле `Тип` выберите тип шаблона.

4. <font color="red">**Версия**</font>: В поле `Версия` — номер версии шаблона. Он управляется системой автоматически при обновлении шаблона.

### Редактор шаблонов

![Редактор шаблонов](/_images/template/template_4.png ':size=80%')

<!-- 📷 Скриншот ожидается: интерфейс редактора шаблонов -->

Нажмите кнопку `Изменить` на шаблоне, чтобы открыть визуальный редактор шаблонов, где администраторы могут:

- Размещать компоненты (например, пункты меню, изображения, текст) на интерфейсе с помощью перетаскивания.
- Настраивать свойства каждого компонента (позиция, размер, цвет, содержимое).
- Копировать компоненты для повторного использования.
- Отменять/повторять операции редактирования.
- Сохранять шаблон и публиковать его на терминальных устройствах.

## Ресурс шаблона

> Введение

![Ресурс шаблона](/_images/template/template_5.png ':size=80%')

<!-- 📷 Скриншот ожидается: страница «Ресурс шаблона» -->

В разделе `Ресурс шаблона` администраторы управляют ресурсами (изображения и т. д.), используемыми шаблонами. Ресурсы загружаются один раз и могут использоваться несколькими шаблонами.

Нажмите кнопку `Добавить`, чтобы загрузить новый ресурс шаблона.

![Ресурс шаблона - Добавить](/_images/template/template_6.png ':size=80%')

<!-- 📷 Скриншот ожидается: загрузка/редактирование ресурса шаблона -->

<font color="red">**Название**</font>: В поле `Название` введите имя, идентифицирующее этот ресурс.

<font color="red">**Тип**</font>: В поле `Тип` выберите тип ресурса.

<font color="red">**Изображение**</font>: В поле `Изображение` загрузите файл ресурса. Загруженный файл будет сохранён на сервере и будет использоваться шаблонами через его путь.
