# Настройка объектов

> Введение

![Настройка объектов](/_images/facilities/facilities_1.png)

В `Меню объектов` администраторы могут создавать группы объектов и управлять информацией об объектах отеля (бассейн, спортзал, ресторан и т. д.). Информация об объектах будет отображаться на терминалах в номерах, что позволяет гостям знакомиться с объектами отеля и достопримечательностями рядом.

## Группа объектов

> Введение

![Группа объектов](/_images/facilities/facilities_group_1.png ':size=80%')

<!-- 📷 Скриншот ожидается: страница списка групп объектов -->

В разделе `Группа объектов` администраторы создают группы для категоризации объектов. Группировка упрощает управление и совместное отображение объектов одной категории на терминале.

Нажмите кнопку `Добавить`, чтобы создать новую группу объектов.

![Группа объектов - Добавить](/_images/facilities/facilities_group_2.png ':size=80%')

<!-- 📷 Скриншот ожидается: окно добавления/редактирования группы объектов -->

<font color="red">**ID**</font>: В поле `ID` идентификаторы управляются и генерируются системой. Заполнять их не нужно.

<font color="red">**Название**</font>: В поле `Название` введите имя, идентифицирующее эту группу объектов, например `Объекты отеля`, `Достопримечательности рядом`.

## Объекты

> Введение

![Объекты](/_images/facilities/facilities_2.png ':size=80%')

<!-- 📷 Скриншот ожидается: страница списка объектов -->

В разделе `Объекты` администраторы добавляют, редактируют и удаляют сведения об объектах. Каждый объект принадлежит одной или нескольким группам объектов и будет отображаться на терминале для просмотра гостями.

Нажмите кнопку `Добавить`, чтобы создать новую информацию об объекте.

![Объекты - Добавить](/_images/facilities/facilities_3.png ':size=80%')

<!-- 📷 Скриншот ожидается: окно добавления/редактирования объекта -->

<font color="red">**Тип**</font>: В поле `Тип` введите название объекта, например `Бассейн`, `Фитнес-центр`.

<font color="red">**Содержимое**</font>: В поле `Содержимое` введите подробное описание объекта. Содержимое будет отображаться на терминале.

<font color="red">**Группа**</font>: В поле `Группа` выберите группу(ы) объектов, к которой принадлежит этот объект. Объект может принадлежать нескольким группам.
