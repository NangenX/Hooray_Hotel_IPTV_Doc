# Настройки Live

> Введение

![Program Menu](/_images/program/program_1.png)

Здесь настраиваются разделы `Live` и `VOD`.

## Live Packages

> Введение

![Live Package](/_images/program/program_2.png)

Здесь создаются категории live-каналов. Категории упорядочивают источники и упрощают поиск. Нажмите `Add`, чтобы добавить категорию; привяжите источники и загрузите постер.

![Live Package-Add](/_images/program/program_3.png)

1. <font color="red">**ID**</font>: генерируется системой; меньший ID — выше в списке (можно менять в редактировании).
2. <font color="red">**Name**</font>: название категории.
3. <font color="red">**Price**</font>: цена; 0 — бесплатно, иначе гостю предложат оплату.
4. <font color="red">**Image**</font>: постер категории.
!>  **Рекомендация: размер постера 300x210**
5. <font color="red">**Live Program Select**</font>: выберите каналы для категории.
6. <font color="red">**STB Select**</font>: выберите устройства, которым доступна категория.

## Live Program

> Введение

![Live Program](/_images/program/program_4.png)

Здесь добавляются/редактируются/удаляются live-каналы (поддерживаются UDP/RTP/HTTP-TS/FLV/RTMP/RTMPS/HLS/DASH и др.). Нажмите `Add`, чтобы создать канал.

![Live Channel Add Detail](/_images/program/program_5.png)

1. <font color="red"> **ID** </font>: генерируется системой; можно править без конфликтов. Меньший ID — выше в списке.
2. <font color="red"> **Name** </font>: имя канала на приставке.
4. <font color="red"> **URL** </font>: адрес потока.
5. <font color="red"> **Image** </font>: логотип канала.

## Радиоканал

> Введение

![Радиоканал](/_images/program/radio_1.png ':size=80%')

<!-- 📷 Скриншот ожидается: страница списка радиоканалов -->

В разделе `Радиоканал` администраторы могут добавлять, редактировать и удалять информацию о радиоканалах. Радиоканалы транслируются как аудиопрограммы на терминальные устройства, что позволяет гостям слушать радиостанции в своих номерах.

Нажмите кнопку `Добавить`, чтобы создать новый радиоканал.

![Радиоканал - Добавить](/_images/program/radio_2.png ':size=80%')

<!-- 📷 Скриншот ожидается: окно добавления/редактирования радиоканала -->

1. <font color="red">**ID**</font>: `ID` генерируется системой автоматически. Чем меньше `ID`, тем раньше радиоканал отображается в списке.

2. <font color="red">**Номер**</font>: В поле `Номер` задайте порядок отображения радиоканала. Чем меньше номер, тем выше его позиция в списке.

3. <font color="red">**Название**</font>: В поле `Название` введите имя радиоканала, например `BBC World Service`. Это имя будет отображаться на терминале.

4. <font color="red">**URL**</font>: В поле `URL` укажите адрес воспроизведения радиоканала. Терминал будет использовать этот адрес для воспроизведения радиопрограммы.

5. <font color="red">**Изображение**</font>: Загрузив соответствующее `изображение` канала, оно будет отображаться в списке радиоканалов на терминале.

## Принудительная прямая трансляция

> Введение

![Принудительная прямая трансляция](/_images/program/forced_play_1.png ':size=80%')

<!-- 📷 Скриншот ожидается: страница управления принудительной трансляцией -->

В разделе `Принудительная прямая трансляция` администраторы могут создать задачу принудительной трансляции: все (или указанные) зарегистрированные приставки будут принудительно переключены на указанный прямой источник в заданном временном окне, а страница воспроизведения будет заблокирована на время задачи. Если гость попытается выйти, терминал автоматически вернётся. Обычно используется для объявлений отеля или обязательных трансляций (например, видео о пожарной безопасности).

### Создание задачи принудительной трансляции

![Принудительная трансляция - Создать](/_images/program/forced_play_2.png ':size=80%')

<!-- 📷 Скриншот ожидается: окно создания задачи принудительной трансляции -->

Нажмите кнопку `Добавить` / `Создать задачу`, чтобы создать новую задачу принудительной трансляции. Одновременно может быть активна только одна задача; создание новой отменит предыдущую активную.

1. <font color="red">**Тип источника**</font>: Выберите источник принудительной трансляции:
   - `Канал прямого эфира`: выберите существующий канал из списка.
   - `Пользовательский URL`: укажите пользовательский адрес потока (должен быть `http`/`https` и не может быть адресом интрасети).

2. <font color="red">**Время начала**</font>: Время начала задачи в формате `yyyy-MM-dd HH:mm`. Также можно начать сразу с указанием длительности.

3. <font color="red">**Время окончания**</font>: Время окончания задачи в формате `yyyy-MM-dd HH:mm`. Время окончания должно быть позже времени начала.

### Мониторинг статуса задачи

![Принудительная трансляция - Мониторинг](/_images/program/forced_play_3.png ':size=80%')

<!-- 📷 Скриншот ожидается: мониторинг задачи/детали устройств -->

После создания задачи страница управления показывает в реальном времени статистику выполнения всех целевых терминалов:

- Счётчики **Ожидает / Отправлено / Выполнено / Ошибка / Истекло** и общее количество терминалов.
- **Детали устройств**: статус команды каждого терминала (Ожидает / Отправлено / Выполнено / Ошибка / Истекло), время отправки, время подтверждения и причина сбоя.
- **История задач**: просмотр всех прошлых задач принудительной трансляции.
- **Повторная отправка**: массовая повторная отправка неудачных команд задачи.
- **Экспорт CSV**: экспорт деталей команд задачи в файл CSV для архивирования.

Нажмите кнопку `Отмена`, чтобы в любой момент отменить текущую активную задачу. После отмены терминалы перестанут принудительно переключаться и вернутся в обычный режим.
