# Системные настройки

> Введение

![System](/_images/setting/setting_1.png) 

В `System` администратор изменяет общие параметры IPTV: импорт лицензии, бэкап БД, настройки безопасности внешних API.

## Setting

> Введение

![Setting - Setting ](/_images/setting/setting_2.png) 

В `Setting` задаются данные, синхронизируемые на терминалы: фоновая графика, формат времени и прочие параметры.

<font color="red">**Monetary Unit**</font>: локальный символ валюты (отображается в Shopping).

<font color="red">**Paid Days**</font>: срок доступа при покупке пакета/фильма.

<font color="red">**Consumption Mode**</font>: способ оплаты гостя. `Prepaid` — расходуются средства счёта; `Advance` — расход в кредит (долг на номер).

<font color="red">**Home Page Show**</font>: фон главной — Image (картинка) или Video (видео).

<font color="red">**Time Format**</font>: формат времени на терминале.

<font color="red">**Favorite Operation**</font>: очищать ли избранное при выезде.

<font color="red">**Request ring**</font>: загрузка тона оповещений (устарело).

<font color="red">**Welcome Background**</font>: фоновое изображение приветствия (синхронизируется на ТВ).

<font color="red">**Home Background**</font>: фон главной страницы.

<font color="red">**Secondary Menu Background**</font>: фон второго уровня меню.

<font color="red">**LOGO**</font>: логотип для ТВ и мобильных клиентов.

<font color="red">**Live Player Watermark**</font>: устарело.

<font color="red">**Vod Player Watermark**</font>: устарело.

<font color="red">**City**</font>: город для получения прогноза погоды.

<font color="red">**Enable Remote Assistance**</font>: устарело.

<font color="red">**Протокол**</font>: В поле `Протокол` выберите протокол прямой трансляции, используемый терминальными устройствами (например, `http`, `udp`, `rtsp`).

<font color="red">**Номер оператора**</font>: В поле `Номер оператора` введите уникальный номер оператора, необходимый для обслуживания системы и технической поддержки. **После заполнения его нельзя изменить.**

<font color="red">**PMS**</font>: В поле `PMS` выберите режим интеграции PMS (системы управления объектом):
- `Нет`: интеграция с PMS отключена.
- При выборе типа PMS заполните `Информацию о сервере PMS` (адрес сервера PMS). Система IPTV будет интегрироваться с PMS (например, для автоматического заезда/выезда гостей и синхронизации счетов). Переключатель, адрес и порт PMS настраиваются администратором.

## Version

> Введение

![APK Version Management](/_images/setting/setting_3.png) 

В APK Version Management настраиваются политики обновления (обязательные/необязательные) для разных терминалов.

`APK Upgrade` — загрузить APK; после выбора файла система считает версию и покажет её в списке, администратор проверяет корректность.

## Настройка потокового медиасервера

> Введение

![Настройка потокового медиасервера](/_images/setting/streaming_1.png ':size=80%')

<!-- 📷 Скриншот ожидается: страница настройки потокового медиасервера -->

В разделе `Настройка потокового медиасервера` администратор настраивает адреса сервера потокового вещания и сервера time-shift (отложенного ТВ), которые используются терминальными устройствами для воспроизведения прямых трансляций и отложенных программ.

<font color="red">**IP потокового медиасервера**</font>: В поле `IP потокового медиасервера` введите IP-адрес сервера потокового вещания.

<font color="red">**Порт потокового медиасервера**</font>: В поле `Порт потокового медиасервера` введите порт сервера потокового вещания.

<font color="red">**IP сервера time-shift**</font>: В поле `IP сервера time-shift` введите IP-адрес сервера time-shift.

<font color="red">**Порт сервера time-shift**</font>: В поле `Порт сервера time-shift` введите порт сервера time-shift.

<font color="red">**Часы time-shift**</font>: В поле `Часы time-shift` укажите, сколько часов программ хранит сервер time-shift, что позволяет гостям просматривать ранее показанные программы в этом окне.

## Графики данных

> Введение

![Графики данных](/_images/setting/charts_1.png ':size=80%')

<!-- 📷 Скриншот ожидается: страница статистики данных -->

В разделе `Графики данных` администраторы могут просматривать статистику работы системы IPTV, включая:

- **Статистика выручки**: общая статистика доходов.
- **Статистика VOD**: статистика просмотров видео по запросу.
- **Тип потребления**: статистика, сгруппированная по типу потребления.
- Месячные столбчатые диаграммы и круговые диаграммы с фильтром по году.
